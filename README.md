## 👩‍💻 About Me
<img align="right" height="150" src="https://i.pinimg.com/originals/8c/76/00/8c760088693d8f28bd0375d3d4ef16c8.png" alt="Rubber Duck Debugging" />

**Software Engineer | Itaú Unibanco**

Software Engineer at Itaú Unibanco, building an enterprise GenAI platform based on a distributed microfrontend architecture.

As part of the founding engineering team, I develop Angular and React microfrontends, as well as backend services using Python and FastAPI. I contribute to AI agent capabilities, including LLM orchestration, Retrieval-Augmented Generation (RAG), semantic search, Model Context Protocol (MCP) tool execution, context management, and long-term memory.

On the backend, I design scalable services following Clean Architecture principles using SQLAlchemy, PostgreSQL, and the Repository pattern, with a strong focus on maintainability, scalability, and security. I also contribute to the development of Backend-for-Frontend (BFF) services that aggregate data, adapt external APIs to frontend requirements, and help isolate client applications from changes and inconsistencies in downstream services. Additionally, I work with JWT-based authentication, user-scoped access control, and solutions built on AWS Bedrock AgentCore.

Additionally, I contribute to application observability with Datadog RUM, AWS deployment pipelines (S3, CloudFront, and API Gateway), and platform improvements focused on scalability, reliability, developer experience, and infrastructure cost optimization.

I continuously expand my knowledge of Large Language Models (LLMs), Transformers, Embeddings, and Machine Learning through Andrew Ng's Machine Learning Specialization, applying these concepts to deepen my understanding of modern AI systems and their real-world applications.
